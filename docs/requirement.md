# 智学 AI 学习笔记系统需求分析

## 1. 项目背景

大学生在课程学习、实训开发和考试复习过程中会产生大量笔记。传统笔记通常分散在本地文档、聊天记录和在线文档中，存在检索困难、知识点不成体系、复习重点不清晰、缺少智能辅助等问题。智学 AI 学习笔记系统以学习笔记为核心对象，结合 AI 摘要、标签推荐、学习建议和问答助手，帮助学习者完成知识整理、复习规划和互动交流。

## 2. 项目目标

系统目标是开发一个符合高校《软件生产实习》要求的前后端分离项目，覆盖需求分析、概要设计、数据库设计、编码实现、接口联调、系统测试、部署说明和 GitHub 版本管理全过程。

## 3. 用户角色

| 角色 | 权限范围 | 主要功能 |
| --- | --- | --- |
| 普通用户 USER | 管理个人数据，查看公开笔记 | 注册登录、笔记管理、AI处理、发布归档、收藏评论、学习统计、AI问答 |
| 管理员 ADMIN | 管理全站数据 | 用户管理、笔记管理、分类标签、公告、评论审核、系统统计、日志查看 |

## 4. 功能需求

### 4.1 用户模块

- 用户注册、登录、退出登录
- JWT 身份认证
- 获取当前用户信息
- 修改个人资料和密码
- 管理员禁用、启用、重置用户密码

### 4.2 笔记模块

- 创建、编辑、删除个人笔记
- 草稿保存、提交 AI 处理、发布、归档
- 我的笔记分页查询
- 公开笔记广场
- 分类、标签和关键词筛选
- 笔记详情展示 Markdown 内容和 AI 结果

### 4.3 AI 模块

- AI 笔记摘要
- AI 标签推荐
- AI 学习重点提取
- AI 考试重点提取
- AI 学习建议
- AI 问答助手
- 支持 mock 模式和 OpenAI 兼容真实 API 模式

### 4.4 互动模块

- 收藏和取消收藏
- 查询我的收藏
- 发布评论和回复评论
- 管理员审核评论

### 4.5 后台管理模块

- 用户管理
- 笔记审核和违规删除
- 分类管理
- 标签管理
- 公告管理
- 评论管理
- 系统统计

### 4.6 学习统计模块

- 笔记总数
- 本周新增笔记数
- 收藏数量
- AI 使用次数
- 分类统计
- 月度学习趋势

## 5. 非功能需求

| 类型 | 需求 |
| --- | --- |
| 易用性 | 页面简洁现代，采用左侧菜单和后台管理布局，支持表格分页、弹窗确认和错误提示 |
| 安全性 | 使用 Spring Security + JWT，普通用户只能操作自己的数据，管理员拥有管理权限 |
| 可维护性 | 后端采用 Controller、Service、Mapper、Entity、DTO、VO 分层结构 |
| 可扩展性 | AI 模块采用可替换设计，后续可接入 OpenAI、DeepSeek、阿里云百炼、智谱 AI、本地大模型 |
| 可靠性 | 统一异常处理、统一返回结果、参数校验、逻辑删除 |
| 可部署性 | 提供 MySQL 脚本、后端启动说明、前端构建说明和 Nginx 部署说明 |

## 6. 核心业务流程

笔记生命周期：

1. 用户创建学习笔记，状态为 DRAFT。
2. 用户保存草稿并继续编辑。
3. 用户提交 AI 处理，状态变为 WAITING_AI。
4. AI 生成摘要、学习重点、考试重点和学习建议。
5. AI 处理完成后，状态变为 AI_FINISHED。
6. 用户确认内容后发布笔记，状态变为 PUBLISHED。
7. 其他用户可以查看、评论和收藏已发布笔记。
8. 用户可将已发布笔记归档，状态变为 ARCHIVED。
9. 用户或管理员可删除笔记，状态变为 DELETED，并进行逻辑删除。

## 7. 笔记状态流转

| 当前状态 | 允许操作 | 下一状态 |
| --- | --- | --- |
| DRAFT | 编辑、提交 AI | WAITING_AI |
| WAITING_AI | AI 处理完成 | AI_FINISHED |
| AI_FINISHED | 编辑、发布 | AI_FINISHED / PUBLISHED |
| PUBLISHED | 查看、收藏、评论、归档 | ARCHIVED |
| ARCHIVED | 查看、删除 | DELETED |
| DELETED | 不展示 | 无 |

## 8. 用例说明

普通用户用例包括注册登录、创建笔记、编辑笔记、提交 AI、发布笔记、归档笔记、收藏笔记、评论笔记、查看统计和使用 AI 问答。管理员用例包括用户管理、笔记管理、分类标签管理、公告管理、评论审核和查看系统统计。
