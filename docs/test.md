# 系统测试文档

## 1. 测试环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows 10/11 或 Linux |
| JDK | 17 |
| Maven | 3.8+ |
| Node.js | 18+ |
| 数据库 | MySQL 8 |
| 浏览器 | Chrome / Edge |

## 2. 测试类型

- 黑盒测试：从用户界面和接口输入输出角度验证功能。
- 接口测试：使用 Knife4j、Postman 或浏览器请求验证 RESTful API。
- 功能测试：验证注册、登录、笔记、AI、收藏、评论、后台管理等功能。
- 权限测试：验证普通用户和管理员访问边界。
- 异常测试：验证参数错误、密码错误、越权操作和非法状态流转。

## 4. 权限测试重点

| 测试项 | 普通用户 | 管理员 |
| --- | --- | --- |
| 查看自己的草稿 | 允许 | 允许 |
| 修改他人笔记 | 禁止 | 允许删除或管理 |
| 访问 `/api/admin/**` | 禁止 | 允许 |
| 禁用用户 | 禁止 | 允许 |
| 管理分类标签 | 禁止 | 允许 |

## 5. 异常测试重点

- 未登录访问需要认证的接口，应返回 401。
- 普通用户访问管理员接口，应返回 403。
- WAITING_AI 状态笔记不允许编辑。
- ARCHIVED 状态笔记不允许评论。
- 用户名重复注册应提示用户名已存在。
- AI API Key 未配置时应自动使用 mock 模式，系统仍可演示。

## 6. 测试结论

系统核心功能、权限控制、笔记状态流转和 AI mock 模式均满足课程实训要求。后续可补充 JUnit 单元测试、MockMvc 接口测试和 Cypress 前端端到端测试，提高自动化测试覆盖率。
